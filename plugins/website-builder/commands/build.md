# Build Website

**Project Name:** `$0`
**Mode:** `$1` (--existing for existing project, omit for new)

---

## Phase 1: Project Analysis

**Goal:** Understand project context

**Actions:**

```
Task(website-architect) Analyze project for website setup.

Detect: Framework, existing pages, content
Check: Site requirements, target audience
Output: Website strategy
```

---

## Phase 2: Site Setup

**Goal:** Set up website structure

**Actions:**

```
Task(website-setup) Create website scaffold.

Requirements:
- Set up framework
- Create page structure
- Configure routing
- Add base styling
- Set up layout
```

---

## Phase 3: Content

**Goal:** Create website content

**Actions:**

```
Task(website-content-agent) Create content.

Requirements:
- Create landing page copy
- Add value propositions
- Write feature sections
- Create CTAs
- Add social proof
```

---

## Phase 4: SEO

**Goal:** Optimize for search engines

**Actions:**

```
Task(website-seo-agent) Configure SEO.

Requirements:
- Add meta tags
- Configure Open Graph
- Create sitemap
- Add schema markup
- Configure robots.txt
```

---

## Phase 5: Analytics

**Goal:** Set up tracking

**Actions:**

```
Task(website-analytics-agent) Configure analytics.

Requirements:
- Add analytics provider
- Set up event tracking
- Configure goals
- Add heatmaps
- Set up funnels
```

---

## Phase 6: Conversion

**Goal:** Optimize for conversions

**Actions:**

```
Task(website-conversion-agent) Optimize conversion.

Requirements:
- Add CTA optimization
- Set up A/B tests
- Configure forms
- Add lead capture
- Set up retargeting
```

---

## Phase 7: Engagement

**Goal:** Add engagement features

**Actions:**

```
Task(website-engagement-agent) Add engagement.

Requirements:
- Add interactive elements
- Configure notifications
- Set up chat
- Add social sharing
```

---

## Phase 8: Verification

**Goal:** Verify website

**Actions:**

```
Task(website-verifier) Verify website.

Requirements:
- Check all pages
- Verify links
- Test forms
- Check mobile
- Validate SEO
```

---

## Summary

**Output:**

```
✅ Website Complete

To add features:
  /website-builder:add page <name>       # Add page
  /website-builder:add section <type>    # Add section
  /website-builder:add seo               # SEO optimization
  /website-builder:add analytics         # Analytics
  /website-builder:add ai-content        # AI-generated content

To run:
  npm run dev
```
