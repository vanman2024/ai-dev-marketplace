# responsive-patterns

Mobile-first responsive design patterns with Tailwind CSS.

## Contents

- Breakpoint strategies (sm, md, lg, xl, 2xl)
- Fluid typography with clamp()
- Touch-friendly UI patterns
- Responsive navigation
- Image optimization

## Usage

Reference this skill when implementing responsive web designs.

## Key Patterns

### Mobile-First
- Base styles for mobile, scale up with breakpoints
- sm:, md:, lg: prefixes for larger screens

### Touch Targets
- Minimum 44x44px tap areas
- touch-manipulation for faster taps

### Fluid Typography
- clamp(min, preferred, max) for scaling text
- Viewport-relative sizing

### Navigation
- Hamburger menu on mobile
- Horizontal nav on desktop
- Proper focus states

## Components

- ResponsiveContainer
- ResponsiveGrid
- ResponsiveNav
- ResponsiveImage
